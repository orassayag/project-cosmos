## Stage 2 — Abortable demo runner with speed scaling (committed 2026-09-26T09:19:14Z)
**Files:** client/src/demo/runDemo.ts, client/src/demo/__tests__/runDemo.test.ts
**What was built:** `runDemo(script, actions, { signal, speed, onStepStart? })` plays steps sequentially through `DemoActions` only, divides durations by `speed`, resolves `'done'`/`'aborted'` (never throws on abort). Exports `sleep(ms, signal)` (clears timer + listener), `scaledDuration(ms, speed)` (for stage 9 animations), and `abortOnTrustedInput(controller, target = window)` (aborts on trusted `pointerdown`/`keydown`, returns cleanup — for stage 8).
**Key decisions:** Call-then-sleep: a step's actions fire at its start, then `durationMs` elapses. `connect` = `setAiStatus('connecting')` → wait → `'connected'`. `ask` = `setSearchPressed(true)` → `min(150, durationMs)` → `setSearchPressed(false)` + `ask(question)` → rest of duration. `onStepStart?(step, stepIndex)` added for stage 9's pointer/caption (runner ignores `target`/`caption`). Abort mid-step skips the closing actions, so stage 8's teardown must reset pressed state and drop the fake AI connection. Non-finite/non-positive speed throws `RangeError`. jsdom `Event.isTrusted` can't be overridden, so `abortOnTrustedInput` takes a `Pick<EventTarget, …>` target and tests pass a fake one.
**User overrides during review:** none.

**What was built:** `useAiConnection({ enabled })` (default `true`) — when `false`, skips `/api/ai/status` and reports `disconnected`/no provider; re-enabling re-runs the status check. `useDemoAiConnection()` returns an `AiConnection`-compatible fake plus `isConnecting` and `setDemoStatus` (stable `useState` setter); provider always `anthropic` (`DEMO_AI_PROVIDER` exported); `connect`/`disconnect` never touch the network.

Real hook shows last-known status (possibly `unknown`) after re-enable until the new check returns. Plan's "no `fetch` during full `ai` script" runner test deferred to stage 7 (needs the `demo=ai` script).
